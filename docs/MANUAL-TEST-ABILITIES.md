## 1. Dev-хелпер (для ускорения теста)

На **localhost** после загрузки доступны две глобальные переменные:

| Выражение | Что делает |
|-----------|-----------|
| `window.__game` | текущий экземпляр игры (все поля/методы `Game`) |
| `window.__placeAbility(kind, idx?)` | ставит плитку-способность (`bomb`/`jelly`/`crab`) на клетку `idx` или на первую пустую, если `idx` не указан; возвращает `{ok, idx, kind}` или `{ok:false, reason}` |

Примеры:

```js
window.__placeAbility('bomb')          // бомба на первую пустую клетку
window.__placeAbility('jelly', 0)      // медуза в левый верхний угол
window.__placeAbility('crab', 12)      // краб на клетку 12
window.__game.abilities                // {enabled, spawnChance, types, spawned, used, cleared, freeze}
```

> Dev-хелпер **недоступен вне localhost** — в проде (VK / Яндекс / боевой URL)
> таких глобальных переменных нет. Это чисто тестовый инструмент.

## 2. Чеклист проверки

### 2.1. Спавн и внешний вид
- [ ] На уровне 6 (5×5) механика включена: `window.__game.abilities` не `null`.
- [ ] На уровне 1 (Лагуна) механика **выключена**: `window.__game.abilities === null`.
- [ ] Плитка-способность отличается от обычной: **пурпурный градиент**, **пунктирная
      рамка**, анимация пульса, глиф (💣 / 🪼 / 🦀) и метка («Взрыв» / «Прилив» / «Краб»).
- [ ] Плитка-способность **не имеет числового значения** (только глиф + подпись).

### 2.2. Активация (тап/клик)
- [ ] **💣 Бомба**: `window.__placeAbility('bomb')`, затем тап/клик по плитке → ряд +
      столбец очищены, счётчик `abilityCleared` увеличился, тост «💣 Взрыв! Убрано N плиток».
- [ ] **🪼 Медуза**: `window.__placeAbility('jelly')` → тап → `window.__game.getAbilities().freeze === 1`,
      тост «🪼 Прилив заморожен на ход!».
- [ ] **🦀 Краб**: `window.__placeAbility('crab')` → тап → две крупнейшие плитки слились
      в сумму (тост «🦀 Слияние в N!»).
- [ ] После активации плитка исчезает, `abilityUsed` увеличился.

### 2.3. Слияние (мягкие стенки)
- [ ] Поставьте способность рядом с обычной плиткой того же значения:
      `window.__placeAbility('bomb', A)` и обычную плитку 2 рядом. Сдвиг **не сливает** их.
- [ ] Обычные плитки того же значения сливаются как обычно (регрессия).

### 2.4. Заморозка прилива (jelly)
- [ ] На уровне с приливом: `window.__placeAbility('jelly')` → активируйте → следующий ход
      прилив **не смывает** нижний ряд; ход после — смывает (заморозка на 1 ход).

### 2.5. Спасательный круг (game over)
- [ ] Заполните доску так, чтобы ходов не осталось, но оставалась плитка-способность
      → игра **не заканчивается** (есть «спасательный круг»).
- [ ] Активируйте бомбу/краба → появился ход → игра продолжается.

### 2.6. Undo и сохранение
- [ ] Активируйте способность, затем Undo → способность **восстановилась** на доске
      (не потерялась), счётчики откатились.
- [ ] Перезагрузите страницу → способность и счётчики `spawned/used/cleared` сохранились.

### 2.7. Блокировки (guards)
- [ ] Во время анимации хода (`_busy`) тап по способности игнорируется.
- [ ] На уровне без механики (`window.__game.abilities === null`) способностей нет,
      `window.__placeAbility` возвращает `{ok:false, reason:'механика выключена'}`.

### 2.8. Ежедневная головоломка
- [ ] В ежедневной головоломке механика **выключена** (`abilities: null`) — на доске
      нет способностей, всё работает как раньше.

## 6. Как разблокировать уровень 6 (если не пройден)

Сейв хранится в `localStorage`. В консоли на localhost:

```js
const s = JSON.parse(localStorage.getItem('ocean2048-save'));
s.unlockedLevels = [1,2,3,4,5,6];
s.currentLevel = 6;
localStorage.setItem('ocean2048-save', JSON.stringify(s));
location.reload();
```

> Ключ сейва может отличаться — проверьте в DevTools → Application → Local Storage.
> После сброса уровня сейв перезапишется (это dev-манипуляция, прод не затронут).
