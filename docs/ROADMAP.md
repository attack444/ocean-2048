## 1. Сюжетная концепция (легенда)

Древний риф накрыл **«числовой прилив»** — аномальные плитки-кораллы засоряют
глубины и тревожат морских обитателей. Игрок — **исследователь глубин**.
Соединяя плитки, он очищает океан слой за слоем, спасает обитателей и
добирается до Хозяина Моря.

### 7 уровней = 7 глубин (уже заложено в `js/levels.js`)

| Уровень | Локация |
|---------|---------|
| Ракушка 🐚 | Лагуна |
| Краб 🦀 | Риф |

| Черепаха 🐢 | Тёплые течения |
| Осьминог 🐙 | Затонувший корабль |
| Акула 🦈 | Океанический жёлоб |
| Хозяин Моря 👑 | Атлантида / Бездна |

## 2. Главная цель: время в игре (retention)

> **Принцип (решение 2026-08-21):** главный показатель веб-игры — **сколько времени
> пользователь проводит в ней**. Вся дальнейшая разработка оценивается через удержание:
> «заскучал → ушёл». Каждая новая фича обязана либо удлинять сессию, либо возвращать
> игрока на следующий день. Уровни и сюжет — инструменты этой цели.

### Петли удержания (что заставляет играть)

1. **Короткая сессия, «ещё один ход»** — партии 2048 короткие, между ними всегда
   есть зацепка: новая цель, недобитый рекорд, почти разблокированный буст.
2. **Прогрессия** — 7 рангов-глубин + достижения: игрок всегда в паре шагов от
   следующей награды (см. §3 Tier A/B).
3. **Ежедневный возврат** — ежедневный бонус (есть) + ежедневные задания (есть) +
   будущие еженедельные челленджи: «зайди завтра, не потеряй серию».
4. **Сюжет и открытия** — сюжетные миссии, новые обитатели-плитки, случайные
   события: контент, который появляется не сразу, а постепенно.
5. **Социальное** — лидерборд VK/Яндекса, шаринг, позже мультиплеер: «сыграть
   лучше друга».

### Как это меряем

- Платформенная аналитика (VK/Яндекс) — сессии, время, возвраты.
- Свои метрики (при переносе на свою экосистему): события `session_start`,
  `level_win`, `game_over`, время партии; `daily`-возврат по облаку.

## 3. План развития (фазы) — «интересно и затягивает»

> **Цель (2026-08-21):** уйти от «просто набрать 256/512/1024…» к игре, которую
> хочется не бросать. Главный фокус — **визуал, анимации, UI/UX** и режимы.
> Каждая фаза = законченный кусок с юнит-тестами, без поломки платформ.

### Фаза 0 — Фундамент: что уже есть ✅

- База 2048 (свайпы/стрелки/WASD/D-pad), 7 уровней-глубин (4×4→6×6).
- Анимации: `tileAppear`, `pulse` (победа), `shake` (тупик), `confettiFall`,
  `combo-pulse`, `modalIn`, `hintFlash`; reduce-motion.
- Магазин (бусты shuffle/bomb/x2), скины, темы, ежедневный бонус/задания,
  достижения, комбо/серии, облако VK/Яндекс, лидерборды, реклама, звук.

### Фаза 1 — «Визуальное сияние» ✅ (готово)

Приоритет — яркие анимации и «сочность» каждого действия.

- [x] **Плитки-обитатели** (вместо «голых» чисел): цифра + эмодзи-обитатель по мере
      роста (2=малёк 🐟 → 8=краб 🦀 → 16=медуза 🪼 → 32=осьминог 🐙 → 64=рыба-меч 🗡️ →
      128=черепаха 🐢 → 256=акула 🦈 → 512=кит 🐋 → 1024=гигантский кальмар 🦑 →
      2048=Левиафан 🐉). Цвет/глиф плитки меняется с ростом.
- [x] **Частицы при слиянии**: всплеск воды/брызги + вспышка цвета в точке слияния
      (легковесный particle-слой на canvas/абсолютных div, с reduce-motion-фолбэком).
- [x] **Пузырьки-фон**: медленно всплывающие полупрозрачные пузырьки за доской
      (CSS-анимация, не мешает геймплею, выключается в reduce-motion).
- [x] **Пульс рекорда + счёт-вверх (count-up)**: число рекорда «вспыхивает» при его
      побитии, очки анимированно «докручиваются» до значения.
- [x] **Анимация появления новой плитки** — плавное «всплытие» с лёгким увеличением
      (уже есть `tileAppear` — причёсан, добавлено отражение/свечение).
- [x] **Тень/глубина**: мягкие тени плиток и доски, лёгкий градиент фона «глубина».
- [x] **Микровибрация/«вжух» на тач**: лёгкий отклик D-pad/свайпа (нативная haptic
      + визуальный отклик на вебе).

### Фаза 2 — «Геймплей: цель ≠ число» (средний объём)

Главное: каждый уровень — не «набери N», а маленькая история.

- [ ] **🗺️ Карта глубин** — визуальный экран выбора уровня вместо простого списка:
      точки-локации (Лагуна → Бездна), анимированные «пройдено/заблокировано»,
      награды за глубину. Даёт прогрессию «в паре шагов от награды».
- [ ] **Сюжетные миссии на глубинах**: цель уровня + доп. миссия
      («Спаси черепаху», «Разбуди коралл», «Очисти затонувший корабль») —
      прогресс-бар миссии над доской, награда жемчужинами.
- [ ] **Смягчение кривой сложности**: промежуточные цели на поздних уровнях
      (под-цели 128/256/512 внутри уровня «Хозяин Моря»), чтобы не бросали на 4096.
- [ ] **Модификаторы механики**:
      - «Коралловая волна» — цепные слияния (3 одинаковые за ход);
      - «Планктон» — шанс выпадения 8 вместо 2/4;
      - «Тёплое течение» — временный ×2 за следующее слияние.
- [ ] **Препятствия**: скалы/якоря — блоки, которые нельзя сдвинуть; «зоны слияния».
- [ ] **Случайные события**: «Шторм» (перемешивание), «Медузий дождь» (несколько
      плиток), «Пузырь» (×2 случайной плитки) — с анимацией и превью.
- [ ] **Дельфин-навигатор (ИИ-подсказка)**: расширить 💡 — подсветка оптимального хода,
      предупреждение «остался 1 ход до тупика».
- [ ] **🧭 «Прилив и отлив»**: периодическое изменение значений плиток по таймеру
      (уникальная механика, аналогов нет в жанре) — вносит вариативность в партию.

### Фаза 2.5 — «Глубина ядра»: ход = решение, а не перекладывание 🧠

> **Откровенно (2026-08-21):** классический 2048 бездумен — в нём нет угрозы, бюджета
> ходов и позиционного мышления, игрок «скидывает плитки в угол». Скины, уровни,
> ежедневки и сезоны — **внешний контур**: они возвращают в игру, но не делают **ядро**
> интересным. «Глубина ядра» добавляет в каждый ход реальное решение: угрозу, бюджет,
> позицию, выбор. Каждая механика — отдельный модуль с юнит-тестами, на океанскую тему.

- [ ] **🌊 «Прилив» (главная угроза)** — каждые N ходов вода поднимается и затапливает
      нижний ряд: плитки в нём «уносит течением» (снимаются со счётом). Игрок обязан
      держать нижние ряды чистыми → настоящая пространственная спешка, а не «складывай
      в угол». Уровень угрозы растёт с глубиной. **Флагман «глубины ядра»**, отлично
      ложится на тему океана.
- [x] **🧮 Ходы как ресурс** — «бесполезный» ход (без единого слияния) наказывается:
      прибавляет шаг прилива или усиливает угрозу. Каждый свайп обязан что-то давать →
      убивает бездумное «перекидывание туда-сюда».
- [ ] **🪸 Позиционные цели** — миссии не «набери N», а «сложи 128 в левом нижнем углу»,
      «создай два 256 рядом» или «построй столбик 2→256». Цель привязана к месту на
      доске → мышление о структуре, а не «максимум очков».
- [ ] **🦈 «Акула-охотник»** — хищник на доске: каждый ход движется к самой большой
      «незащищённой» плитке; догнав — съедает (убирает или понижает). Выбор: пожертвовать
      мелкой плиткой, чтобы увести акулу, или защищать крупную. Уникальная механика.
- [ ] **⚡ Плитки-способности** — редкие плитки с умением, которое игрок сам активирует:
      рыба-бомба 💣 (убрать ряд), медуза-паралич 🪼 (заморозить прилив на ход), краб-щипцы 🦀
      (соединить две плитки в одну). Агентивность: игрок решает когда и как применить.

### Фаза 3 — «Режимы» (средний/большой объём)

- [ ] **Бесконечный режим** (уже есть `infinity`) — вывести в отдельную кнопку меню:
      игра без цели, гонка за максимальной плиткой/очками.
- [ ] **Режим «Челлендж»**: N ходов на цель (таймер/лимит ходов), награда.
- [ ] **📅 Еженедельные челленджи** — привязка к календарю + награды жемчужинами:
      прямой механизм возврата раз в неделю («Эта неделя: собери 1024 за 30 ходов»).
- [ ] **Поле 8×8** — отдельный режим «Бездна» (сейчас 4×4/5×5/6×6).
- [ ] **Скоростной режим** (опц.): против таймера, компактный UI.

### Фаза 4 — «Прогрессия и соревнование» (большой объём)

- [ ] **Система прокачки ныряльщика**: шанс выпадения 4, дополнительный ход,
      «неуязвимость» плитки — покупается за жемчужины/уровни.
- [ ] **Профили** (несколько ныряльщиков на устройстве).
- [ ] **Расширенные лидерборды**: максимальная плитка, скорость до цели, комбо за ход.
- [ ] **Мультиплеер** (дальний): один риф на двоих / параллельные доски.
- [ ] **Гибридные форматы** (самое дальнее): 2048-раннер, тетрис-2048.

### Фаза 5 — «UI/UX полировка» 🟡 в работе (4/6)

- [x] **Онбординг**: интерактивный туториал (6 шагов: жесты, слияние, цель/уровни,
      бусты, магазин), точки-навигация, скип «Пропустить ✕».
- [ ] **Экран выбора уровня** — визуальная «карта глубин» (точки-глубины, прогресс,
      награды за уровень) → перенесено в Фазу 2 (см. 🗺️ Карта глубин).
- [x] **Плавные переходы между экранами** (меню↔игра↔магазин), модалки.
- [x] **Настройки**: темы, скорость анимаций (быстрые анимации ⚡), крупный текст 🔍;
      язык — план.
- [ ] **Микро-тексты и награды**: тост-уведомления уже есть — причесать визуально.
- [ ] **Качество картинки на любом экране**: адаптив для планшетов/десктопа,
      безопасные зоны (safe-area), портрет/ландшафт.

### Фаза 6 — «Смена стиля от прогресса» (вишенка)

- [ ] Фон/интерфейс/звуки эволюционируют по мере прохождения: от светлой Лагуны
      к тёмной Бездне (уровень влияет на палитру, музыку, партиклы).
- [ ] Тематические пакеты скинов: «Космос», «Еда», «Мемы» (после базовых фаз).

### Фаза 7 — «Масштаб: живой океан» (видение будущего) ⭐

> Идеи, которые превращают «2048 с уровнями» в **долгоживущую игру-сервис**.
> Это то, чего не хватает для масштаба: мета-игра, сезоны, коллекция, соревнование
> на весь мир. Крупные — внедряются после базовых фаз, каждая — отдельный
> дизайн-док (см. §5.3) с юнит-тестами.

- [ ] **🌐 Живой Океан (мета-игра)** — карта мирового океана вместо «просто списка
      уровней»: экспедиции в регионы, открытие новых зон, обитатели с историями
      и диалогами. Долгая цель на месяцы — прогрессия не заканчивается на 7 глубин.
- [ ] **📅 Сезоны + «Журнал глубины» (Battle Pass)** — сезонные события по реальному
      календарю (Лунный фестиваль, Зимняя буря), 30–50 ступеней наград, две дорожки
      (бесплатная / за жемчужины). Возврат игрока **каждый день сезона**.
- [ ] **🏛️ Океанариум (коллекция + дом)** — свой аквариум, куда попадают собранные
      плитки-обитатели; декорации, витрина профиля. Completionist-драйв: «собери
      всех обитателей океана».
- [ ] **🗺️ Экспедиции (roguelike-режим)** — процедурные погружения: выбор пути,
      случайные модификаторы, артефакты, глубина растёт с каждой остановкой.
      Бесконечная реиграбельность — каждый заход уникален.
- [ ] **🧩 Ежедневная головоломка (общий сид)** — всем игрокам **одна и та же доска
      в день** (фиксированный seed), соревнование за лучший результат. Wordle-механика:
      вирусный потенциал + ежедневный возврат.
- [ ] **🌊 Глобальные события сообщества** — общая цель всех игроков (например,
      «N миллионов слияний за неделю») → общая награда для всех. Вовлекает всё
      комьюнити сразу, стимул приглашать друзей.
- [ ] **⚔️ Боссы глубин** — сюжетные боссы с новыми механиками (босс двигает плитки,
      блокирует ряды, «съедает» плитки) — награда: уникальные обитатели в коллекцию.
- [ ] **🚢 Корабли-гильдии** — соц-объединения игроков: совместные рифы, командные
      челленджи, общие награды (развитие соцмеханик Фазы 2).

| F | ⚔️ Боссы глубин | сюжетные вершины, уникальные награды | средний |
| G | 🌊 Глобальные события | вовлекает всё комьюнити сразу | средний |
| H | 🚢 Корабли-гильдии | развитие соцмеханик VK, командная игра | большой |

**Быстрые победы «здесь и сейчас»** — №1 (карта глубин) и №4 (еженедельные
челленджи) + **A (ежедневная головоломка)**: ложатся поверх готовой архитектуры
`js/progress.js` и `js/daily.js`, сразу бьют в возврат игрока. А (общий сид) —
самая дешёвая из идей «масштаба» с сильным вирусным эффектом.

## 4. Визуальные принципы (как делаем «красиво и ярко»)

1. **Каждое действие — отклик**: ход → движение плиток + звук; слияние → вспышка +
   частицы; тупик → лёгкий shake; победа → конфетти + пульс рекорда.
2. **Слой анимаций** отделён от логики (`js/effects.js` или CSS-классы) и полностью
   отключается в `reduce-motion`.
3. **Производительность**: частицы/пузырьки на transform/opacity (GPU), не больше
   ~40 одновременных элементов; без reflow на каждый кадр.
4. **Единая палитра океана**: сине-бирюзовые тона, акцент жемчужины 🦪 (золото).
5. **Каждая фича** проходит проверку retention (см. §2): время/возврат/эмоция.

### 5.3 Дизайн-док: Прилив 🌊 (Фаза 2.5, механика №1)

**Суть.** Каждые `N` ходов «вода поднимается» и затапливает нижний ряд: плитки
в нём «уносит течением» (снимаются со счёта). Игрок обязан держать нижние ряды
чистыми → настоящая пространственная спешка вместо «складывай всё в угол».

**Зачем ядру.** Убивает скучную стратегию «копить в углу»: появляется таймер-угроза,
заставляющая принимать решения о каждом ряде. Первый шаг Фазы 2.5 «Глубина ядра»
(за ним — «Ходы как ресурс», позиционные цели, акула-охотник, плитки-способности).

**Правила.**
- Отсчёт: `tideMovesUntilRise` ходов (интервал конфигурируемый, дефолт 8).
- По достижении 0 — смыв: `depth` нижних рядов очищается, за каждую унесённую
  плитку начисляется `scoreReturn` (дефолт 0.5) от её стоимости.
- `tideLevel` (0..depth) — визуальный уровень подъёма воды между приливами,
  для индикатора UI и подсветки «рискованных» рядов.
- Уровень угрозы растёт с глубиной уровня (карта глубин, Фаза 2) — на ранних
  уровнях интервал больше и глубина меньше.

**Конфиг** (`config.tide` в `Game`): `{ enabled, interval, depth, scoreReturn, warning }`.
Без `enabled` механика полностью выключена (обратная совместимость с сохранениями).

**Затронутые модули.** `js/game.js` (логика + `getTide()`, `onTide`), `js/game.test.js`
(юнит-тесты), `js/main.js` + `index.html` + `css/styles.css` (индикатор 🌊 и подсветка
смываемых рядов). Состояние прилива сохраняется в `getState()`/`loadState()`
и откатывается через `undo()`.

**Retention-эффект.** Спешка и риск создают «ещё один ход» внутри партии; смытые
плитки дают частичный возврат очков — игрок переживает прилив как событие, а не
наказание. Проверка: среднее число ходов за партию растёт, вертикальные (вниз)
свайпы остаются рискованными, горизонтальные — безопасными.

### 5.4 Дизайн-док: Ходы как ресурс 🧮 (Фаза 2.5, механика №2)

**Суть.** «Бесполезный» ход — без единого слияния — наказывается: прибавляет шаг
прилива и/или накапливает «напряжение» до порога, после которого срабатывает
«водоворот» 🌪️ — смыв нижних рядов **без** возврата очков. Каждый свайп обязан
что-то давать → убивает бездумное «перекидывание туда-сюда».

**Зачем ядру.** Классический 2048 позволяет «вхолостую» гонять плитки, ничего не
складывая. Механика делает каждый ход решением: либо слияние (прогресс), либо
осознанный риск (ускоряешь прилив и приближаешь водоворот). Второй шаг Фазы 2.5
после Прилива 🌊; работает поверх него (ускорение прилива) и автономно (водоворот).

**Правила.**
- Отсчёт: `movesWithoutMerge` — сколько ходов подряд без слияния (уже был в игре
  для статистики/достижений, теперь он же движет наказание).
- Ход без слияния: `tideStep` (дефолт 1) вычитается из `tideMovesUntilRise`
  (прилив приходит быстрее). Минимум — 1 ход, чтобы игрок не «сжёг» счётчик в 0
  внезапно: смыв всё равно происходит через `_tickTide()`.
- Накопитель: при `movesWithoutMerge === maxWithoutMerge` (дефолт 4) — «водоворот»:
  `depth` нижних рядов очищается **без** начисления очков, `movesWithoutMerge`
  сбрасывается в 0.
- `_tickMovesPenalty()` вызывается в анимационном колбэке **до** `_tickTide()`,
  чтобы водоворот и прилив не смывали одни и те же ряды в один ход.

**Конфиг** (`config.moves` в `Game`): `{ enabled, tideStep, maxWithoutMerge, depth }`.
Без `enabled` механика полностью выключена (обратная совместимость). Если `tide`
выключен, `tideStep` игнорируется — остаётся только водоворот.

**Затронутые модули.** `js/game.js` (логика + `getMovesPenalty()`, `onThreat`),
`js/game.test.js` (юнит-тесты), `js/main.js` + `index.html` + `css/styles.css`
(индикатор 🌪️: заполнение = бесполезные ходы / порог). Состояние сохраняется
в `getState()`/`loadState()` и откатывается через `undo()` (включая счётчик
`movesWithoutMerge` и счётчик водоворотов `threatStrikes`).

**Retention-эффект.** Ходы перестают быть «вхолостую»: игрок ищет слияние даже на
почти заполненной доске, а не «перекладывает» плитки. Проверка: доля ходов без
слияния в партии падает, а осознанные «пожертвования» (сброс мелкой плитки в
водоворот) становятся тактическим приёмом, а не случайностью.

### 5.5 Дизайн-док: Ценность покупок 💎 (магазин: баланс + сундук/донат + бонусы скинов)

**Суть.** Вся валюта и косметика в магазине дают реальный игровой эффект, а у
жемчужин появляется долгосрочный «сток» (куда их тратить). Три оси:

1. **Баланс: сильные бусты и перки.** Каждый буст делает измеримо полезное действие:
   - «Бомба» 💣 — убирает **наименьшую** плитку (`removeLowestTile`): расчищает место,
     не уничтожая собранный прогресс (раньше сносила самую большую — анти-ценность).
   - «Молния» ⚡ — новая, убирает **3 наименьшие** плитки разом (`removeLowestTiles(3)`).
   - «Тройные очки» ✨ — `×3` на 3 хода со слиянием (`activateScoreMultiplier(3, 3)`).
   - Перки: «Дух четвёрки» (шанс 4 → 30%), «Спокойные воды» (+1 ход до прилива),
     «Глубокий старт» (стартовая плитка 8), «Бонусная плитка», «Золотое дно» (+50% монет),
     «Запасные ходы» (+2 отмены).
2. **Сундук и донат.** За жемчужины открывается сундук `openChest` (цена 1500) с
   гарантированной легендаркой (шанс растёт с каждой неудачей — `chestGuaranteed`).
   Очки партии обмениваются на жемчужины (`exchangePointsForDoubloons`, курс 500,
   лимит 3 раза/день). Вкладка доната — пакеты жемчужин за реальные деньги через
   `platform-sdk.js` (на web — демо-режим).
3. **Бонусы скинов/тем.** Каждый скин/тема даёт **+% к очкам за слияния**
   (`appearanceMultiplier` в `Game`): обычные +5…+20%, легендарные (жемчужный,
   бездна, кракен) +25…+50% за 10–50 тыс. жемчужин — дорогая косметика = заметный
   рост счёта, а не просто цвет.

**Зачем ядру.** Без «ценности» покупки обесцениваются: бусты игнорируются,
косметика бесполезна, а выданные 100000 жемчужин некуда тратить. Три оси вместе
дают прогрессию (счёт растёт от косметики), тактику (бусты решают партию) и
долгосрочный расход валюты (сундук/обмен/легендарки).

**Правила.**
- Буст «Бомба» не может удалить единственную ценную плитку по ошибке — только
  минимальную; на пустой доске возвращает `null`.
- Множитель буста очков минимум ×2; бонус скина применяется поверх и не тратит
  заряды буста.
- Легендарная гарантия: при неудаче `chestGuaranteed++` и шанс легендарки растёт
  на `legendaryGuaranteeStep` (0.02), при успехе сбрасывается.
- Обмен очков: дневной лимит `limit` (3) и сброс по `todayKey()` (UTC-дата) — защита
  от фарма.
- Донат-пакеты (`DONATE_PACKS`): 1000/49, 3000/129, 8000/299, 20000/699; на web
  без SDK — демо-выдача минимального пакета.

**Конфиг и модули.** Каталог и цены — `js/shop.js` (`SHOP_ITEMS`, чистые функции
`buyItem/useBoost/ownsPerk/appearanceScoreMultiplier`). Сундук/обмен — `js/chest.js`.
Логика бустов/множителей — `js/game.js` (`removeLowestTile`, `removeLowestTiles`,
`activateScoreMultiplier`, `appearanceMultiplier`, `fourChance`, `tideConfigWithPerks`
в `js/main.js`). UI — `index.html` + `css/styles.css` (панель бустов, сундук 🎁,
обмен, донат, легендарные скины/темы). Тесты — `js/shop.test.js`,
`js/chest.test.js`, `js/game.test.js`.

**Retention-эффект.** У игрока появляется цель копить жемчужины (легендарные скины
до 50 тыс.), повод открывать сундук (гарантированная награда) и тактические бусты
для сложных уровней — возврат к игре ради награды и прогресса, а не «для галочки».
Проверка: доля покупок с эффектом на партию растёт, повторное открытие сундука
(ретеншн «ещё разок») — целевой показатель.
4. UI-тексты и эмодзи — только океанская тема (жемчужины 🦪, без дублонов и казны).
5. **Каждая фича оценивается через retention** (см. §2): что она даёт времени
   в игре / возврату на следующий день. Фичи «для галочки» без эффекта на
   удержание — в конец бэклога.
6. **Платформенная совместимость**: все новые механики работают на всех трёх
   платформах (VK Mini Apps / Яндекс Игры / Web + нативные сборки) через
   `js/platform-sdk.js`; без SDK/модерации — тихий web-режим без сбоев.
7. **Зависимости**: любые библиотеки можно ставить свободно (решение
   2026-08-21), но только необходимые и проверенные; runtime — без лишнего
   веса, всё по HTTPS.
8. **Хостинг VK — временный** (на серверах VK через `vk-miniapps-deploy`),
   после готовности своей 24/7-экосистемы — перенос URL в кабинете VK на свой
   сервер (см. `store/VK_GAMES.md`). Облако и лидерборд VK от смены URL не
   зависят.
