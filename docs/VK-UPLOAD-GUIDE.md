## 1. Деплой на хостинг VK (получение URL)

VK даёт **бесплатный статический хостинг** для мини-аппов. Загружаем туда `build/vk/`.

1. В терминале `D:\pirat` выполните команду:
   ```
   npx @vkontakte/vk-miniapps-deploy
   ```
2. Инструмент выведет ссылку вида:
   ```
   https://oauth.vk.ru/code_auth?stage=check&code=...&revoke=1
   Please open this url in browser (Y/n)
   ```
3. **Сразу** (ссылка живёт ~1 минуту!) откройте эту ссылку в браузере.
   - Если спросит вход — войдите под нужным VK-аккаунтом.
   - Если покажет QR-код — отсканируйте его приложением VK на телефоне.
   - Подтвердите доступ к приложению.
4. Вернитесь в терминал и нажмите **`Y`** (Enter).
   - Инструмент сам дождётся подтверждения и, если код устарел, выдаст новую ссылку
     (повторите шаги 3–4).
5. Дождитесь сообщений **`Deploy success...`** и строк с URL:
   ```
   vk.ru: ...
   iOS & Android: ...
   m.vk.ru: ...
   ```
   Сохраните URL (обычно вида `https://<имя>.vk-apps.com/...`) — он понадобится на шаге 2.

> Альтернатива без браузера (если есть токен разработчика):
> ```
> set MINI_APPS_ACCESS_TOKEN=<токен>
> npx @vkontakte/vk-miniapps-deploy
> ```

## 2. Указать URL в настройках приложения

1. Откройте панель разработчика: https://dev.vk.com → «Мои приложения» →
   выберите приложение **54731343** («Океан 2048»).
2. Перейдите в раздел **«Размещение»**.
3. В поле **«Адрес приложения»** вставьте URL, полученный на шаге 1
   (вид `https://<имя>.vk-apps.com/...`).
4. Нажмите **«Сохранить»**.

## ⚠️ Если что-то не так

| Проблема | Причина / решение |
|---|---|
| «Белый экран» в VK | Сервер шлёт `X-Frame-Options`/`CSP frame-ancestors`, блокирующие VK. Проверка: `curl -sI <URL> \| findstr /i "x-frame-options content-security-policy"`. Нужно разрешить `frame-ancestors https://vk.com https://*.vk.com https://*.vk.me` и не слать `X-Frame-Options: DENY/SAMEORIGIN` для игры. |
| Ссылка «QR код устарел» | Код живёт ~1 мин. Откройте ссылку сразу; после открытия нажмите `Y` в терминале — инструмент выдаст новую ссылку при повторной попытке. |
| Деплой не стартует | Убедитесь, что терминал открыт в `D:\pirat` и есть интернет; при необходимости повторите `npm install`. |
| Ошибки `VKWebApp*` в консоли | Проверьте, что открываете именно по адресу `vk.com/app54731343` (внутри VK), а не локально — вне VK мост имитируется и методы возвращают `false` (это нормально). |
