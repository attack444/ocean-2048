- Модуль `js/weekly.js` (чистая логика + тесты): недельный ключ `YYYY-Www`

  `WEEKLY_POOL` (7 записей `{ levelId, target, movesLimit, reward }`) по неделе,

  расширен под `weeklyActive`. Тесты — `js/weekly.test.js` (20). ✅
