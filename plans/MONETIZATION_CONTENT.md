## 4. Стратегия контента и оформления

### Генерация vs стоки
- **Генерация (наш пайплайн)** — для бренда: иконки, плитки, логотип, схемы,
  тексты, анимации. Уникальность, полный контроль, дёшево для векторных/простых.
- **Стоки (Unsplash/Pexels, бесплатно)** — для фотореалистичных подложек: океан,
  кораллы, подводный мир, технологии. Фотографическое качество почти без токенов.
- **Гибрид (рекомендуется):** фото-сток фон + фирменная типографика и элементы
  поверх. Выглядит дорого, делается быстро, токенов мало. Генерация — только для
  уникальных брендовых элементов.

### Оформление сообщества (сейчас «скромное»)
- **Обложка**: переделать на фотореалистичный подводный мир (сток) + фирменный
  заголовок и CTA поверх (сейчас — абстрактный градиент с плитками).
- **Аватар**: ярче, сочнее, крупная иконка на фото-подложке.
- **Посты/сторис**: единая дизайн-система (палитра есть) + фото-фоны для
  привлекательности, тексты готовит ИИ.
- **Reels**: дают просмотры — делаем серию сценариев.

### Reels (дают реальные просмотры)
Серия сценариев 9:16 — ✅ **готова** ([`make-reels.mjs`](../scripts/make-reels.mjs),
запуск `node scripts/make-reels.mjs [сек]`, выход `store/media/reels/reel-*.mp4` + GIF):
1. `game` — геймплей «как играть» (тизер с механикой).
2. `depths` — «7 глубин океана» (контент/факты, список).
3. `tips` — советы/секреты для игроков (список).
4. `meme` — юмор про 2048 (трендовые мемы).
5. `news` — анонсы обновлений и релизов (список).
Все 5 роликов сгенерированы (MP4 1080×1920, 30fps + GIF-превью). Тексты можно
править в `SCENES` внутри скрипта и перегенерировать одной командой.
