# Визуальная индивидуальность тем + дорожная карта «сочного» визуала

## Проблема

Сейчас у всех 7 тем в «живом океане» один и тот же набор слоёв: рыбы + планктон + пузыри + световые лучи + мерцающие пылинки. Отличаются только **цвета** и пара «бонусов» (медузы у заката/сакуры, листья у осени/сакуры). Пользователь это верно подметил: «у всех пузырьки и свет».

## Цель

Дать **каждой теме узнаваемую «фишку»** — свой характерный элемент и свой баланс слоёв, чтобы переключение темы ощущалось как смена мира, а не только палитры.

## Часть 1. Индивидуальность фонов тем (реализация в atmosphere.js)

### Подход: «сигнатура темы» (signature)

Добавим в конфиг каждой темы поле `signature` — какой характерный элемент рисовать, и управляющие флаги слоёв (`bubbles`, `rays`, `fish`, `plankton`, `shimmer`, `jellies`, `leaves`, `kelp`, `fireflies`). Рендер станет декларативным: какие слои включены — те и рисуются. Это убирает «у всех одинаково».

### Сигнатуры по темам

| Тема | Характер | Сигнатура-фишка | Слои (вкл/выкл) |
|------|----------|-----------------|-----------------|
| **dark** «Лагуна» | классика, сбаланс. океан | стайки рыб + лучи света | рыбы, лучи, планктон, пузыри, шиммер |
| **light** «Лагуна светлая» | яркий мелкий риф | много рыбок + пузырьки-«искры» | рыбы(много), пузыри, лучи, шиммер |
| **autumn** «Осень» | тёплый, листопад | падающие листья + светлячки | листья, светлячки, планктон; **без пузырей** |
| **forest** «Затонувший лес» | зелёный, сквозь кроны | колышущиеся водоросли/лозы + светлячки | водоросли, светлячки, лучи, рыбы; **без пузырей** |
| **sunset** «Закат» | романтика, медузы | стайка светящихся медуз | медузы(больше), шиммер, планктон; **без рыб/пузырей** |
| **abyss** «Бездна» | биолюминесценция | светящиеся точки-«удильщики» + глубокие лучи | планктон(много), шиммер, лучи, рыбы-тени; **без пузырей** |
| **sakura** «Сакура» | нежность, лепестки | лепестки + медузы | лепестки, медузы, шиммер; **без рыб/пузырей** |

### Новые элементы-фишки (добавить в движок)

1. **Водоросли/лозы** (`kelp`) — для леса: вертикальные изогнутые ленты у краёв/по фону, плавно покачиваются от течения. Рисуются как серия дуг с синусоидой по времени.
2. **Светлячки/искры** (`fireflies`) — для осени и леса: точки, которые «загораются» и гаснут с задержкой (не просто мерцание, а вспышки с паузой), тёплого/изумрудного цвета.
3. **Биолюминесцентные точки-«удильщики»** (`anglers`) — для бездны: редкие крупные светящиеся точки с ореолом, медленно дрейфуют.
4. **Управляющие флаги слоёв** — чтобы убрать «пузыри и свет у всех»: у части тем пузыри/рыбы отключаются в пользу фишки.

## Часть 2. Дорожная карта «сочного» визуала (предложения)

### A. Плитки (числа 2048)
- **Градиентные плитки с бликом**: у каждой плитки лёгкий диагональный блик и внутренняя тень — «стеклянность».
- **Плитки-«жемчужины»**: у высоких значений (128+) добавить мягкое свечение-ореол под цвет темы.
- **Анимация появления/слияния**: лёгкий «пружинный» скейл (уже есть?) + вспышка-кольцо при слиянии.
- **Иконки-морские обитатели** на плитках-степенях (рыбка → краб → осьминог → кит) вместо/вместе с числом — «скин цифр».

### B. Доска и клетки
- **Клетки с глубиной**: лёгкая внутренняя тень + блик сверху, чтобы доска «дышала».
- **Подсветка возможных ходов**: мягкая пульсация клеток, куда можно сходить.
- **Рамка-«аквариум»**: у доски полупрозрачная рамка с внутренним свечением темы.

### C. Скины (новые наборы плиток/доски)
- **Скины-«миры»**: «Коралловый риф», «Ледяная бездна», «Золотые пески», «Неоновый риф» — каждый меняет палитру плиток и доски независимо от фона.
- **Скин «Пират»**: деревянные плитки, золотые монеты вместо чисел, карта сокровищ на фоне доски.
- **Скин «Медуза»**: полупрозрачные «желейные» плитки с пульсацией.

### D. Эффекты и UX
- **Волны при свайпе**: лёгкий наклон/сдвиг доски в сторону свайпа.
- **След за плиткой** при движении (короткий шлейф).
- **Параллакс фона**: атмосфера слегка смещается при наклоне/свайпе — глубина.
- **Частицы при наборе очков**: всплеск монет/искр у счётчика.
- **Реакция на таймеры/угрозы**: акула/водоворот — красная виньетка по краям экрана.

### E. Общие
- **Единая система «свечения»**: CSS-переменные `--glow` на тему, чтобы плитки/кнопки/рамки автоматически брали акцент темы.
- **Плавные переходы между темами**: кроссфейд фона при смене темы (не мгновенная замена).
