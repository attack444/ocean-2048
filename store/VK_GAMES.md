# VK Игры (VK Mini Apps) — публикация «Океан 2048»

Гайд по публикации браузерной версии игры на платформе **VK Игры** (VK Mini Apps,
`vk.com` / dev.vk.com). В отличие от Яндекс Игр, VK публикует игру **не архивом,
а по HTTPS-URL** (раздел «Размещение» в панели управления приложением): игра
грузятся в **iframe** VK, поэтому все файлы должны отдаваться по HTTPS и сервер
не должен слать заголовок `X-Frame-Options: DENY/SAMEORIGIN`.

Официальная документация:
- Обзор VK Mini Apps: https://dev.vk.com/ru/mini-apps/overview
- Начало работы: https://dev.vk.com/ru/mini-apps/getting-started
- Запуск приложения (iframe, параметры запуска): https://dev.vk.com/ru/mini-apps/launch-game
- Модерация каталога: https://dev.vk.com/ru/mini-apps/catalog/moderation

Обновлён: 2026-08-22.

Все методы безопасны: вне VK (web/standalone) возвращают `false`/пустые данные,

> **удалены из vk-bridge** (проверено в 3.0.2 и 2.2.2). Актуальный механизм VK —
> серверный `secure.addAppEvent` (запись, после каталога) + `VKWebAppShowLeaderBoardBox`

> ⚠️ На VK облачные сохранения работают **без авторизации** — это платформенное

> от ключа Яндекса `ocean2048` — конфликтов между платформами нет.

## Ключевое отличие: публикация по HTTPS-URL, а не архивом

| | Яндекс Игры | VK Игры |
|---|---|---|
| Формат загрузки | ZIP-архив | **HTTPS-URL** (раздел «Размещение») |
| Хостинг | на серверах Яндекса | **на своём сервере** (или бесплатный `vk-miniapps-deploy`) |
| Игра грузится | в iframe Яндекса | в **iframe VK** |
| SDK | `/sdk.js` (Яндекс) | VK Bridge (`@vkontakte/vk-bridge`) |

У нас игра уже развёрнута на HTTPS:
- Плейграунд: https://5mb2.ru/games/game/ocean-2048
- Статика (прямой URL для VK): **https://5mb2.ru/static/games/ocean-2048/index.html**
- HTTPS настроен (Certbot), политика конфиденциальности: https://5mb2.ru/static/games/ocean-2048/privacy-policy.html

## Требования VK к хостингу и странице

1. **HTTPS обязателен** — VK не грузит мини-апп по http.
2. **Заголовок `X-Frame-Options`**: сервер **не должен** слать
   `X-Frame-Options: DENY` или `SAMEORIGIN` (и `Content-Security-Policy: frame-ancestors`,
   запрещающую VK), иначе iframe VK не отобразит игру. Нужно разрешить
   `frame-ancestors https://vk.com https://*.vk.com https://*.vk.me`.
3. **`VKWebAppInit` обязателен** — вызывается в `init()` платформенного адаптера.
4. **Параметры запуска**: VK передаёт в iframe query-параметры
   (`vk_user_id`, `vk_app_id`, `vk_are_ads_enabled`, `vk_is_app_user`, `vk_language`,
   `sign` и др.) — на них завязано автоопределение хоста в `detectHost()`.
5. Игра должна работать **без ошибок в консоли** (требование модерации каталога).

Проверка X-Frame-Options для нашего сервера (5mb2.ru):
```bash
curl -sI https://5mb2.ru/static/games/ocean-2048/index.html | findstr /i "x-frame-options content-security-policy"
# Если обе строки отсутствуют — iframe VK откроется. Если есть — добавить на сервер
# заголовок, разрешающий frame-ancestors vk.com (см. выше).
```

> ✅ **Исправлено (2026-08-21):** сервер слал `X-Frame-Options: DENY` и CSP
> `frame-src` без `frame-ancestors` для `/static/games/*` — это гарантировало
> «белый экран» в iframe VK. Правка в `services/web/src/middleware/security.js`
> на сервере: для путей `/static/games/*` заголовок `X-Frame-Options` НЕ
> выставляется, а в CSP вместо `frame-src` добавляется
> `frame-ancestors 'self' https://vk.com https://*.vk.com https://*.vk.me`.
> Для остальных страниц (SaaS) защита `X-Frame-Options: DENY` сохранена.

## Сборка VK-версии

```bash
npm run build:vk
# → build/vk/  (index.html, manifest.json, sw.js, privacy-policy.html,
#   css/styles.css, icons/, js/ — 18 модулей: achievements, chest, cloud-sync,
#   combo, daily-login, daily, daily-puzzle, depths-map, game, levels, main,
#   missions, platform-sdk, platform, progress, rewards, shop, sound; build.json)
```

Особенности сборки (`scripts/build-vk.js`):
- `index.html` копируется **без тега `<script async src="/sdk.js">`** — он нужен
  только Яндекс Играм; на VK такой путь привёл бы к ошибке `Failed to load resource`.
- Исключены серверные/нативные модули (`board.js`, `config.js`, `utils.js`, `ui.js`,
  `native-entry.js`, `native-plugins.js`) и все `*.test.js`.
- `build.json` содержит `{ platform: 'vk', version: '1.0.0', jsModules: 18 }`.

## Пошаговая инструкция публикации в VK

> Панель разработчика VK: https://dev.vk.com (войти по аккаунту VK; для создания
> мини-аппа нужен подтверждённый аккаунт разработчика).

### Шаг 1. Создать приложение
1. https://dev.vk.com → **«Создать приложение»** → тип **«VK Mini App»**.
2. Указать название: **Океан 2048**.
3. Получить **App ID** (понадобится для параметров запуска; `detectHost()` уже
   понимает `vk_app_id`).

### Шаг 2. Указать URL игры (размещение)
1. В настройках приложения открыть раздел **«Размещение»**.
2. В поле **«Адрес приложения»** указать:
   ```
   https://5mb2.ru/static/games/ocean-2048/index.html
   ```
3. Сохранить.

### Шаг 3. Проверить запуск в iframe
1. Открыть мини-апп по прямой ссылке (кнопка «Открыть» в панели).
2. Убедиться, что игра грузится **внутри VK** (без белого экрана — это
   свидетельствует о блокировке `X-Frame-Options`).
3. Проверить консоль (F12): нет ошибок загрузки ресурсов, `VKWebAppInit`
   отработал, облако отвечает; кнопка «Таблица» открывает системную
   `VKWebAppShowLeaderBoardBox` без ошибок в консоли.

### Шаг 4. Сделать игру доступной
1. В настройках приложения выставить статус **«Включено»** — после этого игра
   доступна **всем в VK по прямой ссылке** (без модерации каталога).
2. Пока статус не включён — мини-апп видят только администраторы приложения.

### Шаг 5. Подать заявку на модерацию в каталог
1. Раздел **«Каталог»** / «Публикация» в панели приложения.
2. Заполнить карточку (см. «Шпаргалка для карточки» ниже).
3. Приложить **«Описание основных сценариев»** (сценарии использования).
4. Отправить на модерацию. Одобренная игра попадает в каталог VK и доступна
   через поиск/подборки.

## Временный хостинг на серверах VK (решение)

> **Решение (2026-08-21):** до готовности своей экосистемы (24/7-сервер) игру временно
> размещаем на **бесплатном хостинге VK** через `vk-miniapps-deploy`, а после переноса
> своей экосистемы — переключим URL в кабинете на свой сервер. Так игра не зависит от
> простоя нашего VPS и работает 24/7 с первого дня.

VK даёт бесплатный статический хостинг для мини-аппов через утилиту
**`vk-miniapps-deploy`**:
```bash
npm run build:vk                                   # → build/vk/ (без /sdk.js)
npx @vkontakte/vk-miniapps-deploy                  # загружает build/vk/
# выдаёт HTTPS-URL вида https://prod-app<ID>-<hash>.pages-ac.vk-apps.ru/...
```
Этот URL указываем в разделе «Размещение» — файлы хранятся на серверах VK,
свой сервер для игры не нужен. Обновление = пересборка + повторный деплой.

> ✅ **Деплой выполнен (2026-08-22):** приложение 54731343 задеплоено на хостинг VK.
> Прод-URL (все три платформы):
> - vk.ru / iOS & Android / m.vk.ru:
>   **https://prod-app54731343-2ec00e9a1ff3.pages-ac.vk-apps.ru/index.html**
> (ответ HTTP 200). Обновление игры = пересборка `build/vk` + повторный деплой той
> же командой; URL остаётся прежним.

**Перенос на свою экосистему (позже):**
1. Задеплоить `build/vk/` на свой 24/7-сервер по HTTPS (как уже сделано на 5mb2.ru).
2. Проверить, что сервер не шлёт `X-Frame-Options`/`CSP frame-ancestors`, блокирующие VK.
3. В кабинете VK (раздел «Размещение») заменить URL на свой.
4. Убедиться, что облачные сохранения (`ocean2048_save`) продолжают работать
   (они на стороне VK и от смены URL не зависят); таблица — системная
   `VKWebAppShowLeaderBoardBox`, показ не зависит от URL.

**Параллельно (не мешает VK-хостингу):** игра уже развёрнута на 5mb2.ru
(https://5mb2.ru/games/game/ocean-2048) — это наш «запасной» URL и плейграунд
до переноса экосистемы.

## Особенности / риски

- **VK без архивов**: обновление игры = пересборка `build/vk/` + обновление файлов
  на сервере по тому же URL (URL в кабинете менять не нужно).
- **X-Frame-Options** — главная причина «белого экрана» в VK. Если iframe не
  открывается — проверить заголовки сервера (см. команду выше).
- Игра открывается в iframe VK: полноэкранная кнопка не работает — код безопасно
  игнорирует отказ (`requestFullscreen().catch(() => {})`).
- Облако VK (`ocean2048_save`) не пересекается с облаком Яндекса (`ocean2048`) —
  прогресс на каждой платформе независим.
- До модерации каталога игра доступна **по прямой ссылке** при статусе «Включено» —
  этого достаточно, чтобы «люди играли»; каталог нужен для поиска внутри VK.
