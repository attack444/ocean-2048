## Товары «Платежи» — создать в кабинете VK

App ID: **54731343** («Океан 2048»). Путь: dev.vk.com → приложение 54731343 →
**«Платежи»** (или «Монетизация → Платежи») → «Товары» → «Добавить товар».

**`id` товара ОБЯЗАН совпадать с id в `DONATE_PACKS`** — иначе покупка не найдёт пакет.

| id (в кабинете) | Название | Цена, голосов | Жемчужин игроку | Иконка |
|---|---|---|---|---|
| `donate_small` | Мешочек жемчуга | 10 | 1000 | 🦪 |
| `donate_medium` | Сундук с жемчугом | 25 | 3000 | 💰 |
| `donate_large` | Сокровища глубин | 60 | 8000 | 👑 |
| `donate_mega` | Наследие Кракена | 130 | 20000 | 🐙 |

> Значения жемчужин — из [`js/chest.js`](../js/chest.js:129); меняются только в коде.
> Цены в голосах — из поля `votes` там же; в кабинете задаёте те же числа.

## Шаги включения монетизации

### 1. Включить платежи приложения
- [ ] dev.vk.com → приложение 54731343 → **«Платежи»** → включить монетизацию
      (может потребоваться подтверждение / привязка платёжных данных).
- [ ] Создать 4 товара из таблицы выше (id, название, цена в голосах).
- [ ] Товары в статусе «Активен» (не черновик).

### 2. Включить рекламу в игре
- [ ] Там же, в монетизации — включить **рекламные показы** (interstitial + rewarded).
      Код уже вызывает `VKWebAppShowNativeAds` (`ad_format: 'interstitial'/'reward'`).
- [ ] Учесть: реклама может идти только после одобрения модерацией каталога.

### 3. Проверить в песочнице / тестовом режиме
- [ ] Открыть игру по прямой ссылке в VK (статус «Включено»).
- [ ] Открыть экран доната («Жемчужины» → «Пополнить»): каталог загружается
      (`VKWebAppGetOrderItems` возвращает 4 товара).
- [ ] Нажать на пакет → открывается системное окно `VKWebAppShowOrderBox`.
- [ ] Подтвердить оплату голосами → в игре **зачисляются жемчужины**, счётчик
      обновляется, облако сохраняется (`pushCloudSave`).

### 4. (Позже, после каталога) серверная валидация — опционально
- [ ] Сейчас награда выдаётся клиентски после подтверждения окна. Для простой
      казуалки это допустимо.
- [ ] Для защиты от подделки — подключить серверные уведомления VK о покупке
      (Callback / `VKWebAppGetOrderItems` + `orders.getById`) и начислять жемчужины
      на сервере. Откладывается до Фазы 8 (своя экосистема).
