## 5.1 Автоматизация через VK API (`npm run vk:community`)

> Скрипт [`scripts/vk-community.mjs`](../scripts/vk-community.mjs) публикует посты,
> меняет аватар, обложку и описание сообщества автоматически. Работает на чистом Node
> (без зависимостей), ассеты берёт из `store/community/`.
>
> Сообщество определяется автоматически по токену (там, где вы администратор).
> Если у токена несколько сообществ — нужно указать `--group-id <id>` или
> `--group-name <адрес>` (короткий адрес, например `5mb2`).

### Возможности

| Флаг | Действие |
|------|----------|
| *(без флагов)* | всё: посты + аватар + обложка + описание |
| `--posts` | только промо-посты (лента, 1200×630) |
| `--square` | дополнительно квадратные посты (1080×1080) |
| `--avatar` | только смена аватара |
| `--cover` | только смена обложки |
| `--description` | только название и описание |
| `--post <file>` | опубликовать только один пост (например `promo-neobrain.png`) |
| `--pin <id>` | закрепить пост на стене (wall.pin) |
| `--info` | показать состояние сообщества (название, описание, ссылки, стена) |
| `--group-id <id>` | числовой id сообщества (если их несколько) |
| `--group-name <addr>` | короткий адрес сообщества (например `5mb2`) |
| `--dry-run` | показать план без вызовов VK API |
| `--force` | без запроса подтверждения |
| `--publish-date <unix>` | отложенная публикация постов |

### Токены (важно: их два)

> ✅ **Ключ сообщества** (`--token`, настройки сообщества → «Работа с API» →
> «Ключи доступа»): публикует посты (`wall.post`), обложку, описание (`groups.edit`).
> Это и есть основной рабочий ключ для наполнения.
>
> ✅ **Токен приложения** (`--app-token`, alias `--avatar-token`): загрузка
> картинок в посты (`photos.getWallUploadServer` → `saveWallPhoto`) и смена
> аватара (`photos.getOwnerPhotoUploadServer`). Эти методы **недоступны**
> сервисному ключу сообщества (ошибка 27), поэтому нужен отдельный app-токен
> администратора.

**Как получить `--app-token`:** dev.vk.com → приложение → «Настройки» →
«Доступ к API» → «Получить ключ доступа»; включить права **Управление
сообществами** и **Фотографии**.

> ⚠️ Приложения из бизнес-кабинета не могут выдавать standalone-токен
> (старый OAuth отключён, используется VK ID SDK). Для скрипта это не нужно —
> рабочий связки уже достаточно.

**Ограничения VK по типам токенов (проверено на практике):**

| Действие | Ключ сообщества | App-токен |
|---|---|---|
| `wall.post` (пост) | ✅ | ❌ ошибка 15 |
| `groups.edit` (описание/обложка) | ✅ | ❌ ошибка 15 |
| `photos.getWallUploadServer`+`saveWallPhoto` (фото в пост) | ❌ ошибка 27 | ✅ |
| `photos.getOwnerPhotoUploadServer`+`saveOwnerPhoto` (аватар) | ❌ ошибка 27 | ✅ |
| `photos.getOwnerCoverPhotoUploadServer` (обложка) | ✅ | ✅ |
| `photos.getMessagesUploadServer` (фото в ЛС) | ⚠️ photo пустое | ❌ ошибка 15 |
| `wall.delete` (удаление поста) | ❌ ошибка 27 | ❌ ошибка 15 |

### Запуск

```bash
# Показать план (без изменений, ID определяется сам)
npm run vk:community -- --dry-run

# Всё оформление: посты + аватар + обложка + описание
npm run vk:community -- --token <ключ_сообщества> --app-token <app_токен> \
  --group-id 228742910 --no-title --force

# Только посты (4 промо-поста с картинками)
npm run vk:community -- --token <ключ_сообщества> --app-token <app_токен> \
  --group-id 228742910 --posts --force

# Только аватар + обложка + описание (название не меняем)
npm run vk:community -- --token <ключ_сообщества> --app-token <app_токен> \
  --group-id 228742910 --avatar --cover --description --no-title --force

# Если у токена несколько сообществ — укажите id или адрес
set VK_COMMUNITY_TOKEN=токен && npm run vk:community -- --group-id 123 --force
set VK_COMMUNITY_TOKEN=токен && npm run vk:community -- --group-name 5mb2 --force
```

> Токены можно задавать переменными окружения: `VK_COMMUNITY_TOKEN` и
> `VK_COMMUNITY_APP_TOKEN` (или `VK_COMMUNITY_AVATAR_TOKEN`). В командной строке
> `%VAR%` не раскрывается в одной строке с `set`, поэтому надёжнее передавать
> токены прямо аргументами `--token` / `--app-token`.

> **Удаление постов** (`wall.delete`) недоступно обоим типам токенов (27/15) —
> лишние тестовые посты удаляются вручную в интерфейсе сообщества.

> `--group-id` — числовой id сообщества (без знака «−»), берётся из адреса
> `vk.com/club<ID>` или `vk.com/public<ID>`. `--group-name` — короткий адрес.
> Значения можно задать один раз через env `VK_COMMUNITY_GROUP_ID` /
> `VK_COMMUNITY_GROUP_NAME`.

> ⚠️ VK Реклама (ads.vk.com) и загрузка иконки/скриншотов мини-аппа в dev.vk.com
> автоматизировать нельзя — это делается вручную.

### 5.2. Возможности бота и событий (проверено на практике)

**Сервисный ключ сообщества** — полноценный токен для бота:

| Возможность | Метод | Статус |
|---|---|---|
| Отправка сообщений (ЛС, беседы) | `messages.send` | ✅ |
| Inline-клавиатура (кнопки) | `messages.send` + `keyboard` | ✅ |
| Чтение диалогов | `messages.getConversations` | ✅ |
| LongPoll-сервер (реалтайм-события) | `groups.getLongPollServer` | ✅ (включён) |
| LongPoll-настройки | `groups.getLongPollSettings` / `setLongPollSettings` | ✅ |
| Callback-серверы | `groups.getCallbackServers` | ✅ |
| Участники | `groups.getMembers`, `groups.isMember`, `groups.getBanned` | ✅ |
| Онлайн-статус | `groups.getOnlineStatus` | ✅ |
| Права токена | `groups.getTokenPermissions` | ✅ |

Проверено: включён LongPoll (`message_new`, `message_reply`), `messages.send`
отправляет админу (message_id=772), inline-клавиатура работает (message_id=773).
Шаблон-карточка (`template` carousel) → ошибка 911, но для меню достаточно кнопок.

**Ограничения:**
- Товары (`market.get`), документы (`docs.*`), альбомы/фото (`photos.get`),
  обсуждения (`board.getTopics`), статистика (`stats.get`), лид-формы
  (`leadForms.get`) — **недоступны сервисному ключу** (ошибка 27).
- `messages.getConversationMembers` через ключ сообщества — ✅ (только свой peer).
- App-токен (не-standalone) не может: сообщения, LongPoll, Callback (ошибка 15),
  но умеет: стена (`wall.get`), обсуждения, фото, обложка, аватар, загрузка фото в пост.

**Что можно построить на этом:**
- **Бот-автоответчик** в ЛС сообщества (LongPoll → `message_new` → ответ с меню-кнопками).
- **Уведомления админу** (новый подписчик, комментарий, упоминание).
- **Рассылка** по подписчикам (`messages.send` в ЛС; для рассылки сообществом
  VK ограничивает частоту — соблюдать лимиты).
- **Callback-сервер** (если есть публичный HTTPS-адрес) для тех же событий без LongPoll.

  `partner`, `contacts`, `faq`, `help`, `menu`).
- Раздел «Игры» → подкнопки: `howto` (как играть), `invite` (пригласить друзей).
- FAQ по ключевым словам; ответы на «привет/меню/старт» без кнопок.
- Ответы на кнопки обрабатываются через `payload` (команды) и по тексту.
- Уведомления админу о новых диалогах (`--admin`).
- Локальный тест обработчика **без сети**: `--inject "<текст>"`.

**Ключи** хранятся локально в `.env.vk` (файл игнорируется git):
`VK_COMMUNITY_TOKEN` (сервисный ключ), `VK_COMMUNITY_GROUP_ID=228742910`,
`VK_COMMUNITY_ADMIN=259171406`, `VK_COMMUNITY_APP_TOKEN` (для оформления).

**Запуск:**
```bash
# Быстрый тест обработчика (без обращения к VK)
npm run vk:bot -- --inject "как играть в 2048"

# Живой запуск (бесконечно, слушает сообщения) — ключи из .env.vk
npm run vk:bot

# 1 цикл (~25 сек) + приветствие админу — проверка
npm run vk:bot -- --hello --once --timeout 45

# Показать последние сообщения диалога с админом (проверка, что бот ответил)
npm run vk:bot -- --history 12
```

**Проверено на практике (2026-08-22):**
- LongPoll-событие `message_new` принято, бот ответил меню-кнопками.
- В диалоге с админом видны: входящее «привет, чтотыумеешь?» → ответ
  бота «Привет! 👋 ... Выберите пункт меню 👇» → нажатие «👾 Студия» → ответ.
- Тестовые сообщения ранее: `messages.send` (message_id=772), inline-клавиатура
  (message_id=773), приветствие бота (message_id=775).
- Локально (`--inject`) протестированы текстовые запросы: «партнёрство»,
  «игры», «заказать разработку», «как играть в 2048» — возвращают нужные
  разделы с кнопками.

**Примечания:**
- Ключ должен иметь право **«Сообщения»** (настройки → Работа с API → Ключи доступа).
- LongPoll на сообщество включён и работает; шаблон-карусель (`template`)
  недоступен (ошибка 911) — для меню достаточно кнопок.
- Для постоянной работы бота запускайте его как сервис (например, через
  `pm2`/task scheduler или на сервере); локальный запуск — только пока открыт терминал.
