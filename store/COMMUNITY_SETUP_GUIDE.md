# 🛠 Полная инструкция: настройка сообщества VK «5MB2 Digital» в интерфейсе VK

> **Принцип:** где в VK есть **готовый инструмент** (разделы, меню, метки, ссылки,
> закреп, сообщения, реклама) — используем **его**, а не свои скрипты. Так проще,
> надёжнее и не ломается при обновлениях.
>
> Скрипты (`vk-community.mjs`, `vk-bot.mjs`) — только для того, чего в UI нет:
> авто-публикация постов, бот-автоответчик в ЛС.
>
> **Изображения** готовятся отдельно (генератор или подбор/правка по размерам),
> **тексты** — отдельно (раздел 3), **настройка** — вручную по этой инструкции.
>
> Обновлено: 2026-08-22. Связанные документы: [`COMMUNITY_VK.md`](COMMUNITY_VK.md)
> (паспорт + ассеты), [`COMMUNITY_DESIGN.md`](COMMUNITY_DESIGN.md) (дизайн/стиль),
> [`_vk-docs/`](_vk-docs/) (официальные доки VK).

## 7. Метки / теги постов

**Метки** в VK — это теги, которые группируют посты по темам:

1. При создании поста нажмите «Ещё» → **«Добавить метку»** (или поле «Тема»).
2. Заведите постоянный набор меток:
   - `#игры` — релизы и обновления игр (в т.ч. «Океан 2048»)
   - `#neobrain` — всё про SaaS-платформу
   - `#студия5mb2` — работы студии, анонсы
   - `#новости` — новости сообщества
   - `#конкурс` — розыгрыши
   - `#обновление` — патчи/фиксы
3. Одна и та же метка у нескольких постов создаёт **ленту по теме** — подписчик
   может смотреть только их.

> Также у сообщества есть **тематические вкладки/подборки** в ленте (если включён
> соответствующий раздел). Используйте метки стабильно — это бесплатный способ
> структурировать контент и поднять ретеншн.

## 8. Закреплённый пост

**Закрепите Пост 2 «Экосистема»** (написан от сообщества, картинка
`promo-ecosystem.png`) — это лицо хаба (студия + SaaS).

Как закрепить (UI):
1. Откройте пост (id=55 — «Знакомьтесь: 5MB2 Digital…»).
2. Кнопка **⋯** (в правом верхнем углу поста) → **«Закрепить»**.

Через API: `npm run vk:community -- --pin 55 --force`
(сервисный ключ это умеет).

> Закреп меняйте редко — это «первый экран» для нового посетителя.
