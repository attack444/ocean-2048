# Одноклассники (OK) — публикация «Океан 2048»

Гайд по публикации браузерной версии игры на платформе **Одноклассники (OK.ru)**.
ОК — часть единой платформы **VK Games**: тот же VK Bridge, тот же кабинет
`dev.vk.com`, то же приложение (**App ID 54731343**). Отдельного кода под OK не
требуется — игра использует ту же VK-сборку `build/vk/`, SDK-адаптер лишь
выставляет флаг `sdk.ok = true` для отличия окружения.

Официальные источники (доки VK Games, раздел про OK):
- Размещение мини-аппа на дополнительных площадках (в т.ч. OK): «Настройки» →
  «Другие площадки» → «Привязать OK ID» (раздел `mini-apps-placement`).
- Запуск приложения (iframe, параметры запуска): https://dev.vk.com/ru/mini-apps/launch-game
- Модерация каталога: https://dev.vk.com/ru/mini-apps/catalog/moderation
- «Правила размещения приложений в социальной сети "Одноклассники"» — действуют
  дополнительно к правилам VK Games.

Обновлён: 2026-08-25.

## Техническое требование: CSP / frame-ancestors на сервере

OK грузит игру в **iframe ok.ru** (десктоп) и **WebView m.ok.ru** (мобильная
версия сайта). Если сервер шлёт `Content-Security-Policy: frame-ancestors` или
`X-Frame-Options`, не разрешающие `ok.ru`, игра будет отображаться как
«белый экран».

Наш сервер 5mb2.ru обновлён (2026-08-25): для `/static/games/*` заголовок
`X-Frame-Options` не выставляется, а CSP содержит:

```
frame-ancestors 'self' https://vk.com https://*.vk.com https://*.vk.me
  https://vk.ru https://m.vk.ru https://ok.ru https://*.ok.ru https://m.ok.ru
```

Проверка:
```bash
curl -sI https://5mb2.ru/static/games/ocean-2048/index.html
# → Content-Security-Policy: ... frame-ancestors 'self' https://vk.com
#   https://*.vk.com https://*.vk.me https://vk.ru https://m.vk.ru
#   https://ok.ru https://*.ok.ru https://m.ok.ru
```

> ✅ Проверено (2026-08-25): заголовок на 5mb2.ru содержит `ok.ru`/`*.ok.ru`/`m.ok.ru`;
> свежий `platform-sdk.js` (с `ok_app_id`/`ok_platform`/`ok_user_id`) отдаётся по
> https://5mb2.ru/static/games/ocean-2048/js/platform-sdk.js.

## Пошаговая инструкция публикации в Одноклассники

> Панель разработчика: https://dev.vk.com (войти по аккаунту разработчика;
> приложение **54731343** — «Океан 2048», тип VK Mini App, уже создано).

### Шаг 1. Привязать OK ID
1. Открыть приложение 54731343 в кабинете dev.vk.com.
2. Раздел **«Настройки»** → блок **«Другие площадки»**.
3. Нажать **«Привязать OK ID»** — создать/выбрать приложение Одноклассников.
4. Указать адрес игры (URL размещения):
   ```
   https://5mb2.ru/static/games/ocean-2048/index.html
   ```
5. Сохранить. Через ~15 мин игра доступна по прямой ссылке:
   - десктоп: `https://ok.ru/app/vk_app54731343`
   - мобильная версия сайта: `https://m.ok.ru/app/vk_app54731343`
   - (приложение OK на телефоне — через прямую ссылку; в каталог OK игра
     не попадает — только прямая ссылка)
   > Проверять в **браузере под своей учёткой OK** (снаружи без авторизации
   > OK отдаёт 404/страницу входа — это нормально). Если «белый экран» —
   > проверить, что в настройках приложения указан URL
   > `https://5mb2.ru/static/games/ocean-2048/index.html`, сохранить и подождать ~15 мин.

### Шаг 2. Проверить запуск в iframe OK
1. Открыть `https://ok.ru/app/vk_app54731343` (и `https://m.ok.ru/app/vk_app54731343`).
2. Убедиться, что игра грузится **внутри OK** без белого экрана
   (белый экран = блокировка `X-Frame-Options`/`frame-ancestors` на сервере).
3. Проверить консоль (F12): `VKWebAppInit` отработал, облако отвечает,
   флаг `sdk.ok === true` (можно вывести `console.log(sdk.isOk())`).

### Шаг 3. Подготовить магазин к валюте ОКи (IAP, по желанию)
- В OK игровая валюта — **ОКи** (не голоса). Для покупок нужно настроить
  товары/тарифы в кабинете приложения на площадке OK отдельно от VK.
- Код покупок (`VKWebAppGetOrderItems` + `VKWebAppShowOrderBox`) платформенно
  не зависит — применим и в OK.

### Шаг 4. Пройти модерацию каталога OK
1. В кабинете приложения перейти в раздел **«Каталог»** / «Публикация»
   (для площадки OK).
2. Заполнить карточку (см. «Шпаргалка для карточки» ниже — та же, что и для VK).
3. Приложить «Описание основных сценариев».
4. Убедиться в соблюдении «Правил размещения приложений в социальной сети
   "Одноклассники"» (см. чек-лист ниже).
5. Отправить на модерацию. **После одобрения** игра становится доступна всем
   пользователям OK (поиск, подборки, каталог).

## Особенности / риски

- **Белый экран в OK** — почти всегда `X-Frame-Options`/`frame-ancestors` на
  сервере. Если iframe не открывается — проверить заголовки (см. команду выше).
- **Модерация обязательна**: в OK игра НЕ становится доступной всем по прямой
  ссылке сразу (в отличие от VK со статусом «Включено») — нужна модерация
  площадки OK. При этом в каталог OK приложения не размещаются: после
  одобрения игра доступна всем **только по прямой ссылке**
  (`https://ok.ru/app/vk_app54731343`).
- **ОКи ≠ голоса**: валютная модель в OK своя; IAP-каталог и тарифы настраиваются
  на площадке OK отдельно.
- Обновление игры = пересборка `build/vk/` + обновление файлов на сервере;
  URL в кабинете менять не нужно.
- Облачные сохранения (`ocean2048_save`) — платформенное хранилище VK Games,
  работает и в OK.
