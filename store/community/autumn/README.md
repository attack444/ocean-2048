# 🍁 Осенний сезонный комплект (2026)

Сезонный набор ассетов сообщества и постов «Океан 2048» под осень.
Оригинальные («океанские») материалы остаются в [`store/community/`](../) — они
по-прежнему актуальны как базовые; осенняя версия используется **до конца осени**,
после чего можно вернуться к базовой.

Отличия от базового набора: тёплая «закатная» палитра (янтарь/оранжевый), падающие
листья 🍁🍂, осенние подзаголовки в game-креативах. Размеры и структура те же.

## Как генерировать

```bash
# Базовый комплект (в store/community/, без перезаписи осеннего)
node scripts/make-community-assets.mjs

# Осенний комплект (в store/community/autumn/)
node scripts/make-community-assets.mjs --season autumn
```

Осенний режим не трогает оригиналы: он пишет в подкаталог `autumn/`.
